# Forgiving UX checklist

Every screen and every ticket is checked against these rules.

1. **Empty states teach** — explain the concept, show the primary action.
2. **Destructive ops state their blast radius** — "everywhere" vs "only here"; irreversible says so.
3. **Errors speak human** — what happened + what to do next; never raw exceptions.
4. **Wrong input is absorbed** — clear message, no crash, no punishment.
5. **Nothing dead-ends** — unavailable features show a one-line why/where hint, never vanish silently.
6. **Two taps for the irreversible, one for everything else** — no confirmation spam; the diary makes most things reversible.
7. **Copy is snappy, errors are precise** — descriptions in one short sentence; error text names the exact thing that failed, never a vague "something went wrong".
8. **Pages stay uncluttered** — one primary action per screen; features earn their place or live behind a menu.
