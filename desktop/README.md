# cat(a)log desktop

The Rust desktop app of cat(a)log: `catlog-core` holds the Catalog store,
entries, signing, shared-folder sync and bundles; `catlog-l10n` turns the
phone app's ARB files (plus the few desktop-only strings under `l10n/`) into
string tables at build time; `catlog-gui` is the egui shell; the `catlog`
binary opens the window.

```sh
cd desktop
cargo build                                        # debug build
cargo run --bin catlog                             # start the app
cargo fmt --check                                  # formatting
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace                             # all tests
cargo test -p catlog-gui --test render -- --ignored   # PNGs into target/
cargo test -p catlog-gui --test snapshots -- --ignored   # the look, pixel by pixel
tool/coverage.sh                                   # per-crate 80% gate
```

Coverage needs `cargo-llvm-cov` and the `llvm-tools-preview` component. The
render and snapshot tests need a GPU or a software Vulkan such as lavapipe.

The snapshot tests compare the six views and one cat card, drawn over the
fresh fixture, against the PNGs under `crates/catlog-gui/tests/snapshots/`;
CI runs them, so a change in look has to be deliberate. When the look
changes on purpose, redraw the references and commit them:

```sh
UPDATE_SNAPSHOTS=1 cargo test -p catlog-gui --test snapshots -- --ignored
git add crates/catlog-gui/tests/snapshots/*.png
```

A failed run leaves `<name>.new.png` and `<name>.diff.png` next to the
reference to show what moved.

A desk syncs through the shared folder or a `.catsync` bundle; the phones'
in-person sync over hotspot or LAN, the QR scanner, Stray Cam and the video
frame picker need a camera or a radio and stay on the phone.

The shared folder and the `.catsync` bundle are the contract with the
phones; the fixtures under `fixtures/` are generated by the Dart core and
are the specification the Rust core is tested against.

Packaging lives under `packaging/`: the launcher entry and MIME type for
Linux, the packing scripts for Linux (tar.gz, .deb, AppImage), macOS (app
bundle in a dmg) and Windows (zip), and the templates the release renders
into the Homebrew cask, the Homebrew formula and the Scoop manifest.
