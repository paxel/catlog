# 06 — Cards: export & print

**What to build:** A fosterer opens a Cat's Card — Profile Image plus current field values on one screen — and shares it as an image through the platform share sheet, exports it as a PDF, or prints it. This is the original reason the app exists: presentable cards for ten look-alike cats.

**Blocked by:** 03 — Fields + timeline.

- [ ] Output verified manually on a real device (by-eye check is the acceptance)
- [ ] Widget smoke test: card screen renders for a cat with and without photo
